# Responsive Image Slider Library

## Project Description

This project is a responsive Image Slider Library created using HTML, CSS, and vanilla JavaScript.

The project allows users to view different images using Next and Previous buttons and navigation dots.

## Features

- Next button
- Previous button
- Dynamic navigation dots
- Clickable navigation dots
- Smooth sliding animation
- Infinite navigation
- Responsive design
- Mobile-friendly layout
- Image scaling
- Vanilla JavaScript
- No third-party slider library

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
